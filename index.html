Football Schedule Tracker

⚙️ Settings
Schedules, times, TV/streaming info, and scores are fetched automatically from the College Football Data API the moment you add a team, then refreshed every night by a Cloud Function. Nothing here is editable by hand — if something looks off, it'll usually correct itself on the next nightly refresh.

Connect to your Firebase project

Paste the Firebase web config from your project settings (Project settings → General → Your apps → SDK setup). This only identifies which Firestore database to read from — see SETUP.md for the full walkthrough, including deploying the Cloud Functions that actually fetch schedules.
